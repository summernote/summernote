Use inline SVG markup for selected built-in icons

If an icon string starts with markup, the Bootstrap 5 UI helper returns it as-is. That makes inline SVG a clean way to replace the built-in glyphs for just a few buttons.

Example configuration - Inline SVG Icons
summernote.create('#custom-icon-svg-editor', {
  height: 220,
  toolbar: [
    ['insert', ['picture', 'video', 'table']],
    ['view', ['codeview']],
  ],
  icons: {
    picture: pictureSvg,
    video: videoSvg,
    table: tableSvg,
    code: codeSvg,
  },
});
