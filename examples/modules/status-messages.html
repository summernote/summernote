Write alerts and plain text into .note-status-output

The documented notification area still exists in the Bootstrap 5 build. You can target .note-status-output directly and inject Bootstrap-style alerts or lightweight informational markup.

Example configuration - Status Messages
summernote.create('#modules-status-editor', {
  height: 220,
});

const statusOutput = summernote.getInstance('#modules-status-editor')
  .layoutInfo.editor[0]
  .querySelector('.note-status-output');

statusOutput.innerHTML = `
  <div class="alert alert-danger mb-0">This is an error message.</div>
`;
