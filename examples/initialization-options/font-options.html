Curated font lists

fontNames, fontNamesIgnoreCheck, and addDefaultFonts are still useful together when you want a small, intentional font dropdown instead of the broader default list.

Open the font dropdown and switch between Arial, Arial Black, and Merriweather.

This sentence already uses Merriweather so it is easy to compare.

Example configuration - Font Options
summernote.create('#font-options-editor', {
  height: 260,
  toolbar: [
    ['fontname', ['fontname']],
    ['font', ['bold', 'italic', 'underline', 'clear']],
    ['para', ['paragraph']],
  ],
  fontNames: ['Arial', 'Arial Black', 'Merriweather'],
  fontNamesIgnoreCheck: ['Merriweather'],
  addDefaultFonts: false,
});
